## Selected projects

### [AI-Powered YouTube Assistant](https://github.com/priyankaanandd/aichatwithyt) · [Live demo](https://aichatwithyt.vercel.app/)

Ask precise questions about YouTube content through a context-aware RAG pipeline.

- Retrieves transcript context with semantic search in PostgreSQL + pgvector
- Uses LangChain, LangGraph, Gemini, Node.js, and persistent conversation memory
- Handles transcript ingestion through a BrightData webhook and chunking pipeline

### [CodeSync - Real-Time Code Collaboration](https://github.com/priyankaanandd/realtime-codecollab) · [Live demo](https://realtime-codecollab-1.onrender.com/)

Multi-user code collaboration with room-based sessions, synchronized editing, live chat, and compiler support for four languages.

- React frontend with Node.js/Express backend
- Socket.IO/WebSockets for low-latency collaboration

### [URL Shortener](https://github.com/priyankaanandd/URLshortener) · [Live demo](https://urlshortener64.netlify.app/)

Production-style URL shortener with NanoID links, redirects, and click analytics.

- Node.js, Express, MongoDB, REST APIs
